# Resolve the shared local-FDR density bandwidth at an expression value

Resolve the shared local-FDR density bandwidth at an expression value

## Usage

``` r
.getCpUnsLocDensityBwAt(x, densityBw = NULL)
```

## Arguments

- x:

  numeric Expression value.

- densityBw:

  numeric, list or NULL Density bandwidth. Default: NULL.

## Value

numeric Scalar bandwidth, or NA when unavailable.
