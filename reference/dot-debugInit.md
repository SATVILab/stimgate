# Initialise textual debug state for a StimGate run

Initialise textual debug state for a StimGate run

## Usage

``` r
.debugInit(pathProject, reset = TRUE)
```

## Arguments

- pathProject:

  character Path to project directory.

- reset:

  logical Whether to reset existing debug directory. Default: TRUE.

## Value

logical TRUE if debug is active and initialized, FALSE otherwise.
