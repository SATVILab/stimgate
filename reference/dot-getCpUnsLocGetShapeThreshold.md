# Define the optional prefit density-shape threshold

The shape threshold is the lower available value among the first
stimulated antimode to the right of the original main negative peak and
the stimulated density tailgate plus its negative-population-width
margin. The configurable margin fraction is applied to the same width as
the response-search boundary.

## Usage

``` r
.getCpUnsLocGetShapeThreshold(exTblStimThreshold, probTblList, chnlSettings)
```
