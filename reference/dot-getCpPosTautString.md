# Select a cytokine-positive refinement threshold from a taut-string density

The leftmost internal antimode strictly between the marginal lower
boundary and the existing clustered gate is selected. If no such
antimode exists, the existing gate is retained by the caller.

## Usage

``` r
.getCpPosTautString(ex, inc, chnl, cpOrig, peakX, windowWidth, minCell = 10L)
```
