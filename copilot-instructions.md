# GitHub Copilot Instructions

> **Canonical Instructions Notice:** Repository instructions for AI
> coding agents (including GitHub Copilot) are maintained in the root
> `AGENTS.md` file.

Please refer to [`AGENTS.md`](https://satvilab.github.io/AGENTS.md) for
all: - Environment setup and `renv` / CI handling rules - Development
and build workflow commands (`devtools`, `roxygen2`, `styler`,
`lintr`) - Testing standards and best practices - Repository structure
and function conventions - Package policies and guidelines

### Instruction Updates

Do **not** add new shared guidelines or best practices to this file.
Always update [`AGENTS.md`](https://satvilab.github.io/AGENTS.md)
directly so that all coding agents stay aligned with a single source of
truth.
